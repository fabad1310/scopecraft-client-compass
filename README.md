# Scopecraft Client Compass

Necesito una pagina web con un panel administrador oculto (no necesito usuarios y constraseñas, no es tan sensible el tema de los datos), para hacer preguntas y/o cuestionarios a mis clientes, para validar alcances de proyectos. Es decir, necesito desde mi panel poder crear una pagina con un link extension privada que yo le pasaria al cliente para que complete sus respuestas y validar el alcance, para esto necesito que se pueda modificar el titulo y de ahi hacia abajo agregar "componentes" que sean desde:
* Textos planos para aclarar o hacer descripciones
* Preguntas con caja de respuesta
* Preguntas con multiple choices botones


y necesito que me deje seleccionar la estetica para cada formulario, es decir que me permita seleccionar plaetas de colores, fuentes, etc.
Tiene que ser todo SUPER MODERNO y tecnologico, que parezca casi futurista, con animaciones, fondos con movimiento, glow o pulse, etc, que sea todo tecnologia de punta, que cuanto seleccionen un boton tenga animacion, o sonidos, nose, que sea SUPER SUPER MODERNO. 

tambien que me permita poner un logo de la empresa arriba bien grande (y que me deje ajustar el tamaño capaz con un slider o seleccion de tamaño nose). 

Luego que yo creo todo lo que deberia tener, tocaria "CREAR" (deberia dejarme luego "editar" desde mi panel de super administrador) y me genera el link para que compartirle al cliente y que pueda completar todo, y cuando toque "ENVIAR FORMULARIO" se guarde y yo pueda ver las respuestas luego en el panel de administrador de ese cliente. 


Necesito que la estetica sea SUPER CUIDADA, muy muy profesional, moderna.
